diary_sim -- four independent entities write one diary line per tick.
usage: diary_sim [options]      (values: --ticks=N or --ticks N)
  --ticks=N      run up to tick N (an absolute target; no vote)
  --more=N       run N NEW ticks after the lowest common tick (no vote)
  --seed=N       seed for a new run (default 42; existing diaries win)
  --every=N      progress line every N ticks (default 100)
  --fresh        move old diaries/ and entities/ to diaries_old_<time>/
  --home=DIR     save folder (else $DIARY_HOME, else ../diary-data)
  --yes          no question when diaries/ has no *.jsonl (start a new world)
  --preview      simulate in memory, print excerpts, write nothing
  --say=W --text=T  words to a wesen/player/all; --answer: to the petition
  --inbox        print the inbox of Robert
  --grant=P<n>   grant a petition (make grant PETITION=P12): more recovery
  --map          print the treadmill view of the last session end (make map)
  --elo          Elo ranking of wesen and players (chess=1 sessions; make elo)
  --perft        check the chess move generator (perft, draw rules; make perft)
  --govern       the players' decisions, trust, standing (make govern)
  --veto=D<n>    revert a decision (make veto DECISION=D12); --approve=D<n>
  --audit        players' claims vs the truth, misreports (make audit)
  --next         the advice for the next run: wesen, players (make next)
  --next-ticks   the advised ticks, a bare number (nextticks.use=1; make run)
  --trials       the trials (trial=1 sessions; make trials)
  --divergence   players' reports vs the raw votes; dictionary growth
  --dictionary   the official word list the players voted (make dictionary)
  --visit=WHO    stand next to one wesen, watch and talk (make visit WHO=ada)
  --visit-script=F  commands for --visit from a file (else stdin)
  --challenge=P  a caught lie lowers a player's standing (make challenge)
  --robot        the robot: place, battery, camera, who steers it (make robot)
  --screens      the wesen's text screens after the replay (make screens)
  --ledger[=full] where each wesen's mood comes from (make ledger; report only)
  --menu         the main menu (terminal only; make menu)
  --verbose      the whole report on the console (see below; DIARY_VERBOSE=1)
  --report       print the last run_report.txt of the save folder (make report)
  --debug        also write debug_digest.txt (make run|demo DEBUG=1)
  --debug-section=NAME  print one block of debug_full.txt (drift trace players
                 inbox run ledger preport status); nothing is simulated
  --crash-at=T   force a failure at tick T (shows the error trace)
  --help         this text
Wesen (entities): ada (engineer), gemini (reviewer), replika (vice_president),
robert (human). State: energy 0..100, mood -100..100, location 0..3
(ranges, word-game limits, vote thresholds: data/limits.txt; wording:
data/words.txt, data/messages.txt; vocabulary: data/vocab.txt).
Names SHOWN: data/names.txt (id = Name, also for the players); ids, files,
hashes and diaries never change. Rest (new sessions, rest=1): each wesen has
its own recovery rate, a quick rest after work restores less, a work burst
starts a cool-down (limits.txt rest.*); R lines in sessions.txt.
Actions: rest work explore talk wander bench propose, chosen by weights from
a Rule 30 personality plus energy/mood/words (data/limits.txt rule30.*,
lean.*). Talk may teach a word, explore and wander may coin one; a taught word
arrives as a "learn" event. Propose files a petition (a wish for a change;
topics: data/topics.txt) into petitions.txt: attach it for the agenda.
Diaries: diaries/<id>.jsonl, append-only. Every run replays ticks 1..N and
verifies the stored lines (ts ignored), then appends the rest.
Working folder entities/<id>/: words.txt, bench.txt (NOT a VM).
Start: 'import OK / FAILED' says what was read from disk. End: a report
(turns, words, benches, petitions), 'export OK' (files re-read and counted),
run_report.txt (the complete report), summary.txt/.jsonl, a vote table.
The console shows a short form: entity table, petitions, session lines, the
players' boxes, an @@TRACE marker (build seed session ticks anomalies files
sections) and "Full report: <path>". --verbose (make run VERBOSE=1, or
DIARY_VERBOSE=1) prints everything; --report (make report) prints the last
run_report.txt (sections as "== name ==", previous run: run_report_prev.txt).
debug.txt (<= 1500 bytes) is written on EVERY exit; attach it to chat messages.
Ctrl-C / SIGTERM stop cleanly after the current tick (exit 130, status QUIT).
Old diaries (before this version) are incompatible: use --fresh.
Errors: last_error.txt (seed, tick, entity, exception, traceback); paste it
if asked. Back up diary-data/ between tests. Exit 130: quit by signal.
Menu: only make menu (--menu, terminal) and the bare program on a terminal show
it (intro, DIARY title, New Game/Load Game/Inbox/Settings/Quit); make run and
make play AUTO-LOAD: 'Save folder: <path>', 'Found N sessions, T ticks -
continuing' (or 'No save found - creating it') come first. Text: data/menu.txt.
End of session: each wesen (the 4 entities) names a favourite word, recorded
in diaries/sessions.txt (W lines) and verified on import.
Record-first layer (karma, rebirth, unrest, anchor, awareness) + players who
write reports to Robert: diaries/inbox.txt (make inbox, menu Inbox). Robert
speaks between sessions: make say PLAYER=<p> or WESEN=<w> TEXT="..." (else
all); make answer TEXT="..." (the latest petition); AS=name. Replay-verified.
make menu: the main menu.
make run | make play [TICKS=N EVERY=100 SEED=42 YES=1]: build, load the save,
run TICKS new ticks (--more). Copy a backup into ../diary-data/diaries first.
Without --ticks/--more/TICKS the 4 entities VOTE the session length (data/
kalpas.txt: 60 counts, short/medium/long; the median, kalpa.min..max in
limits.txt). diaries/sessions.txt records and verifies it; a crashed
session resumes toward the same target. Edited kalpas.txt: use --fresh.
No diaries yet: a terminal is asked 'Generate a new one? [y/N]' (N: exit 0,
nothing written); without a terminal an explicit length starts fresh, else
exit 2 (use --yes / YES=1). Drift at import is a 3-line stop, not a crash.
Debug digest: --debug writes debug_digest.txt (line 1: status <= 200 B, then
anomalies, only what changed since the last digest, cap debug.digest_bytes =
1500 in limits.txt, dropped lines named) + debug_full.txt; demo: only the
digest, in the current folder. make run SECTION=<name> (drift trace players
inbox run) prints one block.
make demo: PREVIEW only (--preview): 200 ticks of a new world in memory, one
screen of excerpts, nothing written to disk.
make run / play keep ONE persistent world and continue it. It lives in the save
folder ../diary-data (next to the source folder; --home / $DIARY_HOME): delete
the old source folder after an update, the save stays. 'Saved to <path>' ends
every run. Copy diary-data to back it up.
Treadmill world (world=1, new sessions): an endless grid generated on demand
from the seed (data/things.txt); each wesen has (x,y) and takes one step when
it wanders/explores; office lab cafe home are 4 landmark regions near (0,0)
(nearest one = location). Talk needs a wesen on the same/next cell. Verbs
examine push eat greet meet things and teach new words (names, feel, taste,
greetings; dialects by one-letter drift). Only edits are stored:
diaries/world.txt (replay-verified), L lines in sessions.txt. world.enabled = 0
in limits.txt keeps the old behaviour; see docs/WORLD.md. make map shows it.
Player reports (preport=1, new sessions get the marker): the LAST thing of
every run is ONE framed text box (80 columns, 15 lines): a header and a short
paragraph per player (the 4 deities; names: data/names.txt): petitions that
came to it, what it decided (the D records: always true), how its wesen are
doing (as it claims), its top concern; wording varies; also in
player_reports.txt. A player may colour the happiness it reports (up to +-30
mood points) and how many
petitions came lately, by an honesty trait from its Rule 30 personality, trust
and standing (data/preport.txt, limits.txt preport.*). The true values sit next
to the claims in diaries/preports.txt (P lines, replay-checked: DRIFT if
changed or removed). make audit: claimed vs true, misreports, the biggest.
make challenge PLAYER=<name>: a caught liar loses a little standing (Q line in
diaries/challenges.txt, applied from the next tick). preport.enabled = 0 in
limits.txt: nothing changes. See README.
Next run (nextticks=1, new sessions get the marker): at the end of a session
each wesen proposes a tick count from its state (data/ticks.txt: open and
deferred petitions, unrest, tiredness, Rule 30 curiosity; 100..1000 by 100),
each player decides (mean of its wesen, own preference, honesty), the median
is shown in the box ("Next run: 400 ticks (wesen asked a/b/c/d, players
settled on w/x/y/z)") and recorded in diaries/nextticks.txt (replay-checked).
make next shows how. Advice only; with nextticks.use = 1 in limits.txt a
make run without TICKS runs it; TICKS=n always wins. nextticks.enabled = 0:
nothing changes.
Player 4 (players4=1: new sessions get the marker; an old save gets it from
its next new session, no --fresh): a 4th player with its own personality,
trust, watcher, decisions, honesty and box; players4.enabled = 0 in
limits.txt: 3 players as before. make say PLAYER=Amaterasu (or 4).
Visit (visit=1 session; make visit WHO=<name|id|1-4> [TICKS=n]; --visit): you
stand next to ONE wesen for n ticks (default visit.ticks in data/visit.txt, 60;
a normal explicit session). Each tick a frame (80x24, one write) shows its 5x5
view, its screen, mood, energy, what it does, who and what is near. At the
prompt: say <text> (it knows only its own words; the others are shown as
unknown to it; it answers only with words it knows, from data/visit.txt
templates by mood, energy, petitions, trust: short and odd at first, richer
with its vocabulary), teach <word> (data chance, caps per tick and visit),
show (a screen of base words), wait [n] (an empty line = wait 1), leave.
Trust of the wesen towards you moves by small numbers (limits.txt visit.*).
Every input is a line of diaries/visit.txt, replay-verified (tamper = DRIFT).
--visit-script FILE or a pipe: the commands without a keyboard; EOF = leave.
visit.enabled = 0 in limits.txt: no visits. STEP 2 (possess / steer) is only
a hook, see README.
Trial by chess (trial=1 session; needs chess and govern; make trials): a
dispute (clashing petitions, an appeal against a refusal, rival claims to a
coined word, rest against work) between two wesen, a wesen and a player or two
players is settled over the board: best of 3 games, colours alternate; level =
a further match of 3, then 5, ... (odd) until decided; past trial.max_games a
Rule 30 coin. A losing wesen adheres with trial.adhere_pct (less unrest, more
standing), else "refused the trial" and pays standing. Small effects. T lines
of diaries/trials.txt, replay-verified. trial.enabled = 0: no trials.
Records (records=1 session; needs govern): diaries/votes.txt, petitions.txt,
dictionary.txt, announcements.txt, replay-verified. Wesen propose words, the
players vote (majority, caps per session), agreed words go to the dictionary;
wesen and players may announce what they expect (awareness against standing).
make divergence: claims vs raw votes. make dictionary. records.enabled=0: off.
records=2 session: a meaning is a base word, never repeated while agreed,
pending or recently rejected (rec.mean_cooldown). rec.quality=0: records=1.
Secret ballot (records=2): up to rec.alt_max forms per meaning, the players
pick one (plurality, die on a tie); only Robert sees it: diaries/ballots.txt,
make ballots (--ballots). Players, reports, dictionary never show it.
Size (make footprint, make small): bin/diary_sim (-g -O0) is ~9 MB, of which
~4 MB is debug info and symbols. make small builds bin/diary_sim_small (-Os,
no -g, gc-sections, stripped): ~2.9 MB, same output. See README, Footprint.
