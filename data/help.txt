diary_sim -- four independent entities write one diary line per tick.
usage: diary_sim [options]      (values: --ticks=N or --ticks N)
  --ticks=N      run up to tick N (default 1000)
  --seed=N       seed for a new run (default 42; existing diaries win)
  --every=N      progress line every N ticks (default 100)
  --fresh        move old diaries/ and entities/ to diaries_old_<time>/
  --crash-at=T   force a failure at tick T (shows the error trace)
  --help         this text
Entities: ada (engineer), gemini (reviewer), replika (vice_president),
robert (human). State: energy 0..100, mood -100..100, location 0..3
(ranges, word-game limits, vote thresholds: data/limits.txt; wording:
data/words.txt, data/messages.txt; vocabulary: data/vocab.txt).
Actions: rest work explore talk wander bench propose, chosen by weights from
a Rule 30 personality plus energy/mood/words (data/limits.txt rule30.*,
lean.*). Talk may teach a word, explore and wander may coin one; a taught word
arrives as a "learn" event. Propose files a petition (a wish for a change;
topics: data/topics.txt) into petitions.txt: attach it for the agenda.
Diaries: diaries/<id>.jsonl, append-only. Every run replays ticks 1..N and
verifies the stored lines (ts ignored), then appends the rest.
Working folder entities/<id>/: words.txt, bench.txt (NOT a VM).
Start: 'import OK / FAILED' says what was read from disk. End: a report
(turns, words, benches, petitions), 'export OK' (files re-read and counted),
run_report.txt (long), summary.txt/.jsonl, a vote table.
debug.txt (<= 1500 bytes) is written on EVERY exit; attach it to chat messages.
Ctrl-C / SIGTERM stop cleanly after the current tick (exit 130, status QUIT).
Old diaries (before this version) are incompatible: use --fresh.
Errors: last_error.txt (seed, tick, entity, exception, traceback); paste it
if asked. Back up diaries/ between tests. Exit 130: quit by signal.
make demo: build + short run in demo_run/.
