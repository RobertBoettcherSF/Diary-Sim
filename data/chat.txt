# Every line typed or answered is a C line of diaries/chat.txt (record-first, replay-verified): the answers are built from these templates
# and the replayed state with a hash die, so a replay reproduces them.  CHANGING THIS FILE changes the answers of a replay: a save that has
# chat=1 sessions then reports DRIFT for the old chat lines (like data/visit.txt).  Copy the old file back, or start a new save.
# Text: plain ASCII, no line breaks, the answer is cut to chat.reply_chars (data/limits.txt, 150) at a word boundary.
#
